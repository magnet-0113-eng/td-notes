# Jekyll

[GitHub ページと Jekyll について - GitHubドキュメント](https://docs.github.com/ja/pages/setting-up-a-github-pages-site-with-jekyll/about-github-pages-and-jekyll)

> Jekyllは、GitHub Pagesに組み込まれている静的サイトジェネレータで、ビルドプロセスを容易化できます。 JekyllはMarkdownおよびHTMLファイルを取り込み、選択したレイアウトに基づいて、完成された静的ウェブサイトを作成します。 


## .nojekyll

[Bypassing Jekyll on GitHub Pages - The GitHub Blog](https://github.blog/news-insights/the-library/bypassing-jekyll-on-github-pages/)

> .nojekyllという名前の空ファイルを作ると、Jekyllの変換機能を使わずに純粋な静的ホスティングを利用できます。
